RDF QUERY ASSISTANT

Query the connected graph using natural language

kchat inspects the graph schema, generates read-only SPARQL, and summarizes the returned data. Each successful query includes the exact SPARQL and complete JSON or Turtle result for review.

01

Query process

The assistant checks the available classes and predicates before generating and executing SPARQL.

02

Result artifacts

Use the pills below each answer to inspect or download the executed query and its complete result.

03

Query restrictions

SELECT, ASK, CONSTRUCT, and DESCRIBE are supported. Updates and federated SERVICE clauses are rejected.

CONFIGURATION

Graph connection

Set SPARQL_ENDPOINT to a mounted RDF directory or remote endpoint. Authentication and execution limits are configured with environment variables documented in environment.example.

Mounted RDF

docker run -p 8000:8000 \
  -v "$PWD/rdf:/rdf:ro" \
  -e SPARQL_ENDPOINT=/rdf \
  -e LLM_API_KEY="$MISTRAL_API_KEY" \
  kchat:dev

Remote endpoint

SPARQL_ENDPOINT=https://data.example/sparql
SPARQL_BEARER_TOKEN=••••••••
LLM_MODEL=mistral/mistral-small-latest

kchat graph assistant
